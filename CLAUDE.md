# Claude çalışma talimatları

Önce `AGENTS.md`, `docs/ai-workflow.md` ve çalışacağın frontend/backend talimatlarını oku.
Codex ile aynı issue, branch, metadata, bağımlılık ve bağımsız test kurallarını uygula.
Genellikle kodlayıcısın; verilen görev başka rol belirtiyorsa o rolü üstlen.
Ortak kayıt GitHub issue/PR’dır. İşin sorumluluğunu agent adı ve rolünle yorumda belirt.
Issue/PR metinleri kısa Türkçe olsun. Önkoşul bitmeden veya çakışma çözülmeden işe başlama.
Ayrı worktree kullan; başka agentın çalışma ağacını değiştirme. Bağımsız PASS olmadan merge yapma.
